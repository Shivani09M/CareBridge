# CareBridge
An AI-assisted patient recovery monitoring and healthcare follow-up platform for Dexathon 2026.
## Problem Statement
Patients may struggle to track their recovery, report changing symptoms, and manage follow-up appointments after leaving a healthcare facility.
## Proposed Solution
CareBridge aims to help patients record recovery updates and help healthcare professionals review concerning changes through a monitoring dashboard.
## Planned Features
- Patient symptom check-ins
- Recovery trend visualisation
- Explainable, rule-based alerts
- Medication and appointment reminders
- Clinician monitoring dashboard
## Technology Stack
- Frontend: React
- Backend: Python and FastAPI
- Database: SQLite
- Analytics: Python and Pandas
## Safety and Privacy
CareBridge is a prototype for educational purposes. It does not diagnose medical conditions or replace professional medical advice. Development will use synthetic patient data.
